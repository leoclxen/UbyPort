Podporované modely Gemini Flash

Aplikace automaticky detekuje a volí nejnovější dostupný model (Gemini 2.5 Flash / 2.0 Flash / Flash Latest) s kaskádovým fallbackem, takže nehrozí chyba nedostupnosti starší verze modelu pro váš API klíč.

Ochrana API klíče

Klíč se ukládá do privátního virtuálního souboru api_vault.key (OPFS), který nemá veřejnou webovou URL adresu. Pro přenos na jiné zařízení slouží zašifrovaný soubor auth_vault.js chráněný vaším PIN kódem.
